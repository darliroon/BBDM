# CBBDM 相对原始 BBDM 的技术改动点

> 基线：https://github.com/xuekt98/BBDM（CVPR 2023, BBDM: Image-to-image Translation with Brownian Bridge Diffusion Models）
> 本仓库改动：7 个文件修改（+163/-40 行）+ 6 个新文件；**桥的数学公式零改动**

## 1. 条件注入机制（核心创新）

### 原版的问题

BBDM 没有"第三条件"的概念：

- 模型中 `context` 参数的默认值就是源图 A 自己（`context = y if context is None else context`）
- UNet 对一切非 `nocond` 条件一律沿通道维 concat 进输入（`x = th.cat([x, context], dim=1)`）
- 4 个官方配置模板全部关闭 `use_spatial_transformer`，cross-attention 机器存在但从未启用

因此"桥走 A→B，同时注入一个与桥无关的外部条件 C"在原架构中没有插槽。

### 改动

新增 `condition_key: "ImageContext"` 条件类型：C（卫片）经独立编码器编码为 token 序列，通过 UNet cross-attention 注入，**不与 A 在像素/潜空间叠加**。

**新模块 `ImageContextEncoder`**（`model/BrownianBridge/cond_encoder.py`）：

```
C (B,3,256,256)
  → 3 × [Conv2d(stride 2) + GroupNorm + SiLU]   # 下采样 256 → 32
  → 自适应池化到 token_grid × token_grid
  → flatten → (B, 1024, width)
  → Linear 投影到 context_dim + 位置嵌入        # (B, 1024, 512)
```

三个关键设计：

| 设计 | 目的 |
|---|---|
| **proj / pos 零初始化** | 训练第 0 步 C 的贡献恒为 0，模型表现为纯 A→B；C 的影响随训练从零渐进长出（ControlNet 式引入，不扰动近域桥） |
| **可学习 null_embedding** | 条件丢弃（CFG 训练）与无条件采样时的占位 token |
| **token 空间位置与 A/B 对齐** | A 从 C 提取、同坐标系，UNet 各层特征可按空间位置查询 C 的对应区域 |

**打通注入路径的两处基础修改**：

- `openaimodel.py`（UNet forward）：`condition_key == 'ImageContext'` 时跳过 concat
- `attention.py`（CrossAttention）：增加 `context.ndim == 4` 判断——4D 图像照旧 rearrange 成 token；已是 `(b, n, d)` 的预 token 化序列直接使用（原版无条件假设 4D 输入）

## 2. Classifier-Free Guidance（推理期 C 影响力可调）

**训练**：`cond_dropout = 0.1`，10% 样本将整个 C token 序列替换为 null embedding。

两个目的：

1. 解锁推理期 guidance：`ε = (1+w)·ε(C) − w·ε(∅)`，`guidance_scale` 可调 C 的影响力
2. 对抗信息冗余：本任务中 A 是 C 的要素子集（A⊂C），模型可能只靠 A 就拟合训练分布而完全忽略 C——dropout 强制模型学出"有 C 时用 C"的行为

**推理**：`p_sample` 内置 CFG 公式；`sample_to_eval` 支持配置 `guidance_scale`。

`sample(A, C)` / `sample(A, ∅)` / `sample(A, C_shuffled)` 的对比同时是 **C 有效性检验手段**：若输出几乎不变说明 C 被忽略。

## 3. 三元组数据管线

- **`custom_triple` Dataset**（`datasets/custom.py`）：读 `{train,val,test}/{A,B,C}` 同名文件配对，带数量与文件名一致性断言
- **几何同步**：A/B/C 由相同 index 驱动翻转决策（原版 `custom_aligned` 对 A/B 独立掷硬币——A 与 C 有空间对应关系时，独立翻转会破坏对应）
- Runner 四处解包点（`loss_fn / sample / sample_to_eval / get_latent_mean_std`）支持三元组，**向后兼容原二元组**（nocond 等 legacy 路径不受影响）
- 评估输出新增 `context/` 目录，保存采样时的 C

## 4. 训练参数覆盖

- `get_parameters()`：返回 UNet + ImageContextEncoder 参数（原版只有 UNet）
- EMA：按参数名追踪 `requires_grad` 参数，编码器自动被覆盖
- `apply(weights_init)`：编码器先应用通用初始化，再 `reset_zero_init()` 夺回零初始化

## 5. 潜空间版适配（LatentBrownianBridgeModel）

- `condition_key='ImageContext'` 分支：**C 不经 VQGAN**，走自己的 ImageContextEncoder（卫片与车道线图域差异大，不应共享为重建优化的编码器）
- A/B 的 VQGAN 编码、latent mean/std 统计路径与原版一致
- 采样链路同样支持 `c` 与 `guidance_scale`

## 6. 环境兼容修复（不改行为）

| 修复 | 原因 |
|---|---|
| 删 `ReduceLROnPlateau(verbose=True)` | torch 2.13 移除了 `verbose` 参数，原代码在新环境直接崩 |
| 新增 `datasets/__init__.py` | 原版缺失，本地包被 HuggingFace `datasets` 库遮蔽导致 import 错乱 |

## 7. 配置与选型

- **像素空间为主**（`configs/Template-CBBDM.yaml`，256² UNet ch128 mult(1,2,4,8,8) attn(32,16)）：A/B 是 2-3px 细线二值图，VQGAN（自然图像训练）压缩有吃线/通道渗色风险 → 本任务下像素空间是必选
- 潜空间版模板保留为备选（`Template-CBBDM-Latent-f4.yaml`），用前需验证 VQGAN 对通道隔离线图的重建质量
- UNet 开启 `use_spatial_transformer: True, context_dim: 512, transformer_depth: 1`（原版全部关闭）
- 训练启动脚本 `shell/CBBDM.sh`

## 桥数学：零改动

前向 `x_t = (1−m_t)·B + m_t·A + σ_t·ε`、反向过程、m_t/variance_t 调度、`predict_x0_from_objective` 全部保持原样。A 仍是桥端点（近域变换的结构保证），C 只是去噪器的辅助输入——这是对 BBDM 论文核心主张（直接建模域间转换，而非条件生成）的尊重与延伸。

## 数据流对比

```
原版 BBDM:   A ──桥──► B                    （A 可能额外 concat 进 UNet）

CBBDM:       A ──桥──► B                    （桥数学一字未改）
             C ──► ImageContextEncoder ──► cross-attn   （新通路，与 A 零叠加）
             训练: 10% 丢 C 学 CFG          （新机制）
             推理: w 可调 C 影响力          （新能力）
```

## 验证状态

CPU 冒烟测试全链路通过：训练收敛（tiny 模型 loss 0.797→0.452）、`sample_to_eval` 四目录输出、无条件采样、CFG guidance、dropout 生效、零初始化语义（apply 后 context 恒 0、C 注入点梯度 > 0）、`nocond` 原路径回归。
