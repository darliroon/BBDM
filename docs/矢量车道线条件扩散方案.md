> 目标读者:从零接手的代码实现 agent。本文档自包含,按顺序读完即可开工,不需要阅读 StrokeFusion / CBBDM 论文。

> 技术血统:表示法与扩散范式来自 StrokeFusion(AAAI 2026, arXiv 2503.23752);条件注入设计来自本仓库 CBBDM 的 ImageContextEncoder(`model/BrownianBridge/cond_encoder.py`);执行框架(注册表 / Runner / config)沿用本仓库现有约定。

## 0. 一页速览

**任务**:给定断裂、不规则的车道线矢量片段集合 A 与卫星图 C,生成完整、规则的车道线矢量集合 B。

**一句话架构**:把每条车道线编码为一个潜向量,整张图是"潜向量 + 包围框 + 可见标志"组成的**无序集合**;用 DDPM 在该集合上做扩散,去噪网络是**无位置编码的 Transformer**,通过两层 cross-attention 分别查询 A 的片段 token 与 C 的卫图 token。

```
训练:
  A 片段 ──StrokeEncoder──► A tokens ─┐
                                      ├─► VecDenoiser ──► 预测噪声 ε̂
  C 卫图 ──ContextEncoder──► C tokens─┤        ▲
                                      │   加噪的 B 潜码集合 z_t
  B 完整线 ──StrokeEncoder(冻结)──► z_0 ──加噪──┘

推理:
  纯噪声集合 ──VecDenoiser 迭代去噪(A/C 条件)──► 干净潜码集合
  ──MLP拆分/可见性过滤/包围框反归一化──► StrokeDecoder ──► 64点折线 × N 条 ──► 矢量JSON
```

**两阶段训练**:先训 StrokeVAE(编码器+解码器重建),再冻结编码器训 VecDenoiser(扩散)。

**新代码全部落在以下文件**(见 §7):`model/VectorLane/`、`datasets/custom_vector.py`、`runners/VectorLaneRunner.py`、`configs/Template-VLD.yaml`。

## 1. 任务定义与符号

| 符号 | 含义 |
|---|---|
| `A` | 断裂/不规则车道线矢量片段集合,数量不定,可为空 |
| `B` | 完整车道线矢量集合(ground truth),数量不定 |
| `C` | 卫星图,RGB 图像,画布同尺寸 |
| `Np` | 每条线重采样后的点数,固定 **64** |
| `Ns` | B 侧集合槽位数(含 padding),取训练集 B 线数的 99 分位,默认 **32** |
| `Na` | A 侧片段槽位数(含 padding),默认 **96** |
| `d_z` | 单条线的潜码维度,默认 **128** |
| `T` | 扩散步数,**1000**(DDPM) |
| `B`(上下文) | batch size(注意与线集合 B 区分,文中线集合写作"线集合 B") |

**关键约定:画布坐标系**。画布尺寸 `W×H`(默认 256×256,与 C 一致),像素坐标 `x∈[0,W), y∈[0,H)`,y 轴向下(图像惯例)。所有归一化基于此坐标系,见 §3.4。

## 2. 数据规范

### 2.1 源数据格式(输入侧契约)

每个样本一个 JSON 文件,与 C 图像同名配对(如 `0001.json` ↔ `0001.png`):

```json
{
  "image_size": [256, 256],
  "A": [
    {"points": [[x, y], [x, y], ...]}
  ],
  "B": [
    {"points": [[x, y], [x, y], ...]}
  ]
}
```

- `A` / `B`:线段数组;每条线是像素坐标折线(点数 ≥ 2,无序);
- `A` 允许为空数组(完全无输入的极端样本);
- 目录布局沿用现行三元组约定:`dataset_path/{train,val,test}/{A,B,C}/同名.{json|png}`。

### 2.2 预处理算法(严格按此实现)

对每条线(无论 A 还是 B)执行:

1. **RDP 简化**:`epsilon = 1.0` 像素,去掉冗余顶点(仅去冗余,不改变形状);
2. **弧长均匀重采样到 64 点**:沿折线累计弧长,等弧长取 64 个点,**强制保留首点与末点**;
3. **stroke 级归一化**:计算该线自身的轴对齐包围框 `(x0, y0, x1, y1)`;
   - 用长边做各向同性缩放:`s = max(w, h) + eps`,`u = (x − cx)/s + 0.5`、`v = (y − cy)/s + 0.5`,其中 `(cx, cy)` 为包围框中心 → 点落入约 `[0,1]²`;
   - 记录该线的全局包围框向量 `bbox = (cx/W, cy/H, s/W, s/H)`(中心/尺度均相对画布归一化,中心∈[0,1],尺度∈(0,1])。
   **注意**:反归一化必须用与正归一化**完全相同**的 `s` 和 `cx, cy`(即存 `bbox`,不是重新算)。
4. **pen state 通道**:64 点序列附加第 3 通道 `m`,前 63 点 `m=0`,第 64 点 `m=1`(序列终止符;车道线场景恒定,保留它是为了 Decoder 通用性)。

### 2.3 训练张量(collate 之后)

一个 batch 内:

| 名称 | 形状 | 说明 |
|---|---|---|
| `a_points` | `(B, Na, 64, 3)` | A 片段的归一化点序列(u, v, m) |
| `a_bbox` | `(B, Na, 4)` | A 片段全局包围框 |
| `a_mask` | `(B, Na)` | bool,真实片段为 True |
| `b_points` | `(B, Ns, 64, 3)` | B 线的归一化点序列 |
| `b_bbox` | `(B, Ns, 4)` | B 线全局包围框 |
| `b_mask` | `(B, Ns)` | bool,真实线为 True |
| `c_img` | `(B, 3, 256, 256)` | 卫图,to_tensor 且归一化到 [−1,1](与现行管线一致) |

**padding 规则**:槽位不足的补零,`*_mask` 置 False。A/B 各自随机打乱槽位顺序(集合无序,打乱可防止模型记忆槽位语义)。

**数据增强**:仅水平翻转,**A/B/C 必须同步翻转**(A/B 的所有点 `x → W − x`,C 图像 `torch.flip(dims=[3])`),同一随机数驱动——与现行 `custom_triple` 的共享翻转约定一致。

### 2.4 坐标生命周期表(防错核心,实现前抄进代码注释)

| 阶段 | 坐标空间 | 范围 | 携带者 |
|---|---|---|---|
| 源 JSON | 画图像素 | `[0, W)×[0, H)` | points |
| 重采样后 | 画图像素 | 同上 | points |
| stroke 归一化后 | 线局部坐标 | ~`[0,1]²` | `*_points[:, :, :, :2]` |
| 全局位置 | 画布归一化 | 中心/尺度 ∈ `[0,1]` | `*_bbox` |
| StrokeEncoder 输入 | 线局部坐标 | `[0,1]` | `points` |
| StrokeDecoder 输出 | 线局部坐标 | `[0,1]` | 重建点 |
| 反归一化后 | 画布归一化 | `[0,1]²` | `点 + bbox` 复原 |
| 最终输出 | 画图像素 | `[0, W)×[0, H)` | 输出 JSON |

**复原公式**( Decoder 输出 `(u,v)`、预测包围框 `(cx, cy, s)`,画布归一化单位):
`x = (u − 0.5)·s + cx`、`y = (v − 0.5)·s + cy`(结果再乘 W/H 即像素;允许少量越界,clamp 到画布)。

## 3. 模块规格

### 3.1 StrokeEncoder(共享于 A 与 B)

输入 `(B*, N, 64, 3)`(B* 为展平后的线总数),输出 `(B*, d_z)`。

```
Linear(3 → d_model) + 正弦位置编码(64)          # d_model = 128
→ 6 × TransformerEncoderLayer(d_model=128, nhead=8, ff=512, prenorm, batch_first)
→ Attention Pooling: 可学习 query (1, 1, 128) 多头注意力汇聚 → (B*, 128)
→ Linear(128 → 2·d_z) → (μ, logσ²),重参数化采样 z ∈ R^128
```

输出附加:潜码后接 LayerNorm 便于扩散稳定(经验项)。

### 3.2 StrokeDecoder

输入 `(B*, d_z)`,输出 `(B*, 64, 3)`。

```
Linear(d_z → 128) → expand 为 (B*, 64, 128)(可学习 64 位置模板 + 广播)
→ 6 × TransformerDecoderLayer(或 EncoderLayer,d_model=128, nhead=8)
→ Linear(128 → 3)   # (u, v, m̂);u,v 过 sigmoid 压回 [0,1],m̂ 不过
```

### 3.3 ContextEncoder(卫图 C → token)

**直接复用** `model/BrownianBridge/cond_encoder.py::ImageContextEncoder`(含零初始化投影、null_embedding、`null_tokens` 接口):

- 输入 `(B, 3, 256, 256)`,输出 `(B, 1024, 512)`(token_grid=32);
- 零初始化使训练初期 C 贡献≈0(ControlNet 式渐进引入);
- `cond_dropout` 机制内置,用于 CFG。

### 3.4 VecDenoiser(核心去噪网络)

输入:

| 张量 | 形状 | 说明 |
|---|---|---|
| `z_t` | `(B, Ns, D)` | D = d_z + 5 = 133(潜码 128 + bbox 4 + v 1) |
| `t` | `(B,)` | 扩散步索引 ∈ [0, T) |
| `a_tokens` | `(B, Na, 512)` | A 片段条件 token(见下) |
| `a_mask` | `(B, Na)` | bool |
| `c_tokens` | `(B, 1024, 512)` | 卫图条件 token |

A 条件 token 的构造:A 的每个片段经 StrokeEncoder(冻结)得 `(B, Na, 128)`,Linear 投影到 512 后与其 bbox(4 维,投影到 512)相加,再加一个可学习 "A-type embedding"(与 C token、噪声 token 可区分)。padding 槽位的 token 置零,attention 时用 `key_padding_mask` 屏蔽。

**网络结构**(Pre-Norm,全部 batch_first):

```
t → 正弦嵌入(128) → MLP → t_emb (B, 512)

h = Linear(133 → 512)(z_t)
repeat 16 次:
    h = h + SelfAttn(LN(h))                       # 无位置编码 → 置换不变
    h = h + CrossAttn(q=LN(h), kv=a_tokens, key_padding_mask=~a_mask)
    h = h + CrossAttn(q=LN(h), kv=c_tokens)
    h = h + t_emb                                  # 时间步加法注入
    h = h + MLP(LN(h))                             # FFN 512→2048→512
out = Linear(512 → 133)(h)                          # 预测 ε̂
```

参数量约 60M(16 层 × 512 维)。**禁止在 `z_t` 或 self-attn 中引入任何位置编码**,置换不变性是集合生成的前提。

## 4. 训练

### 4.1 阶段 1:StrokeVAE 预训练(重建)

- 数据:A 与 B 的**所有**真实线(不分来源,一个共享 VAE);
- 编码器/解码器见 §3.1/§3.2;
- 损失:

```
L_vae = λ_vec · mean_over_points |(u,v) − (û,v̂)|₂²          # λ_vec = 1.0
      + λ_pen · BCE(m, m̂)                                     # λ_pen = 0.1
      + λ_kl  · KL(q(z|x) ‖ N(0,I))                           # λ_kl = 1e-4 (warmup: 前 5k 步线性升到目标值)
```

- 优化:Adam lr=1e-4,cosine 或沿用现有 ReduceLROnPlateau;batch(按线数计)≥ 512 线/step;
- **验收(过)**:在 val 集上,重建点平均误差(反归一化回像素后)< 2.0 px;渲染 20 张重建结果人眼无肉眼可见断线。

### 4.2 阶段 2:扩散训练(冻结编码器)

目标向量的构造(对每个样本):

1. 真实线的 slot:编码器输出 `z_i`(detach),拼 `bbox_i` 与 `v_i = +0.1`;
2. padding slot:全零潜码、零 bbox、`v = −0.1`(与论文一致的连续值,直接参与加噪);
3. 前向加噪(DDPM,β 线性 1e-4→0.02,T=1000):`z_t = √ᾱ_t·z_0 + √(1−ᾱ_t)·ε`,整条向量(D=133 维)统一加噪;
4. 网络预测 ε,损失在**全部 slot**(含 padding)上计算:`L = mean ‖ε̂ − ε‖²`。

**条件丢弃(CFG)**:仅对 C 做,`cond_dropout = 0.1`(沿用 CBBDM 的 ImageContextEncoder 内置机制);**A 不丢弃**(A 是任务定义的一部分,推理时永远存在)。A 数量为 0 的样本(空 A)自然退化为"A 零 token + C 条件"。

**优化**:Adam lr=1e-4,β=(0.9, 0.999),weight_decay=0;batch_size 16 起(显存不足降 8 + 梯度累积 2);EMA decay 0.995 沿用现有 `runners/base/EMA.py`(覆盖 VecDenoiser + ContextEncoder 参数)。

### 4.3 Stage-B 增强(可选,Phase C)

- StrokeEncoder 加 UDF 分支(StrokeFusion 的视觉监督):每条线渲染 64×64 UDF 图(公式:`I(g)=max over 线段 max_r exp(−γ|g−p(r)|²)`,γ=8.0),6 层 CNN(4→128 通道)分支与点分支特征 concat 后融合;解码侧加反卷积 UDF 重建头 + 感知损失。仅当 Phase B 的线形质量不达标时启用。

## 5. 推理

```python
# 伪代码:单样本采样
z = randn(1, Ns, 133)                        # 纯噪声集合
a_tokens, a_mask = encode_A(A)               # 冻结 StrokeEncoder + 投影
c_tokens = context_encoder(c_img)             # 卫图

for t in reversed(range(T)):                 # T=1000; DDIM 加速可用 50 步
    eps = net(z, t, a_tokens, a_mask, c_tokens)
    if cfg_scale > 1.0:                       # CFG 仅对 C
        eps_null = net(z, t, a_tokens, a_mask, null_c_tokens)
        eps = (1 + cfg_scale) * eps - cfg_scale * eps_null
    z = ddpm_posterior(z, eps, t)             # 标准后验更新

# 拆解
z_stroke, b_hat, v_hat = z[...,:128], z[...,128:132], z[...,132:133]   # MLP_split 可选
keep = v_hat.squeeze(-1) > 0                  # 可见性阈值
for slot in nonzero(keep):
    pts_local = stroke_decoder(z_stroke[slot])            # (64, 3) ∈ [0,1]
    pts_canvas = denormalize(pts_local, b_hat[slot])       # §2.4 复原公式 → [0,1]²
    line = clamp(pts_canvas * [W, H], 0, W-1/H-1)          # → 像素坐标
    output.append(line)
```

**输出**:`results/xxx/B_pred.json`(同 §2.1 schema 的 `B` 字段)+ 渲染 PNG(`B_pred/`,画线宽 3px,红色,与现行栅格评估管线兼容)。

## 9. 陷阱清单(高频 bug,逐条自查)

1. **两级归一化混用**:唯一允许持有全局位置信息的是 `bbox`;点序列里绝不能混入画布坐标。反归一化必须复用正向的 `s/cx/cy`,不得重算。
2. **padding 污染**:padding slot 的 `v=−0.1` 是扩散目标的一部分(网络必须学会输出"此处无线");损失**不要** mask 掉 padding slot。但 A 条件的 cross-attention **必须** mask 掉 A 的 padding。
3. **位置编码**:VecDenoiser 的 self-attention 严禁加位置编码(破坏置换不变);StrokeEncoder/Decoder 内部**必须**加(点序列有序)。
4. **槽位打乱**:每 epoch 对 A/B 的槽位随机重排,否则模型会记忆"第 k 条线"的先验。
5. **翻转同步**:A(所有点)、B(所有点)、C(图像)用同一随机数,参考现行 `custom_triple` 的实现。
6. **v 的连续性**:`v` 是连续标量(±0.1)直接加噪/去噪,不是离散分类;推理以 `v̂ > 0` 阈值过滤。
7. **CFG 只作用于 C**:A 在推理时永远提供;`guidance_scale > 1` 才走双前向分支。
8. **timestep 嵌入**:加法注入即可;若改 AdaLN 需同步改 block 结构,二选一勿混用。
9. **VAE 冻结**:`train_stage='diffusion'` 时 `requires_grad_(False)` + `eval()`;EMA 只追踪可训练参数(沿用现有 EMA 按名过滤的实现)。

## 附:与本仓库 CBBDM 的关系

- CBBDM 的桥数学(布朗桥 A→B)在本方案中被替换为条件生成(B 为生成对象,A 为条件)——这是路线 1 的定义;若未来想保留桥,可将 `z_t = √ᾱ_t·z_B + ...` 换为 `x_t = (1−m_t)·z_B + m_t·z_A + σ_t·ε`,但要求 A/B 集合逐元素对齐(断裂场景需先做笔画匹配),复杂度更高,暂不推荐。
- `ImageContextEncoder`、EMA、optimizer/lr_scheduler 配置段、Runner 注册与接口签名全部复用;`main.py`、`Register.py`、现有模型零改动。
